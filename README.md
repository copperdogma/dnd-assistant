# D&D Assistant

Cam's umbrella for tools that help a human GM keep a physical RPG table moving: sound, maps, references, props, and possible future coordination between them. **D&D Assistant is a working name.** This is a lightweight Markdown project, not an application or a replacement for its component repositories.

Started **2026-10-24** from Cam's direction, existing project documents, and local notes. The longer-term virtual DM vision is preserved as optional exploration; useful assistance at a human-led table comes first.

## Start here

- [Ideal](docs/ideal.md): the outcome we want.
- [Scope and decisions](docs/scope.md): what Cam has specified and what remains open.
- [Components](docs/components.md): existing tools, local locations, status, and reuse boundaries.
- [Ideas and integration concepts](docs/ideas-and-integrations.md): sourced ideas and explicitly proposed connections.
- [Constraints and next steps](docs/constraints-and-next-steps.md): failed experiments, open questions, and a small next move.
- [Sources and setup record](docs/sources.md): provenance, unpublished material, verification, and coverage limits.

For future Codex threads, read [AGENTS.md](AGENTS.md), then scope and constraints before changing anything. Component status is a dated evidence snapshot, not a claim of present deployment readiness. Projection is optional throughout.
